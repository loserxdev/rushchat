## Scoring Mechanism

Honor points are calculated based on the following factors:

### 1. Online Time

- Every 60 minutes online = 1 point
- Automatically calculated, real-time update
- Cumulative calculation

### 2. Invitations

- Every successful invitation = 10 points
- Calculated immediately when user registers

### 3. Message Count

- Every 100 messages sent = 1 point
- Cumulative calculation

### 4. Message Likes

- Each like = 2 points
- Real-time calculation

### 5. Contract Recommendations

- Each contract recommended = 5 points
- Calculated immediately when recommended

### 6. Recommendation Score

- Average voting score × 10
- Calculated based on other users' votes
