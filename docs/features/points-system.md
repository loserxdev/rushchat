# Points System

RushChat's points system is used to incentivize user participation and channel creation.

## Points Acquisition

### Registration Reward

New users automatically receive initial points upon registration.

### Build Incentive

- Can claim 1,000 points daily
- Can only claim once per day
- Requires manual click to claim

### Invitation Reward

Successfully inviting a registered user earns:

- **10,000 points**
- **5 channel contribution points**

### Channel Contribution

Users registered through invitation link, inviter earns:

- **5 channel contribution points**

Channel contribution points are used to unlock channel special features (planned).

## Points Consumption

### Create Channel

- **Regular users**: Need 100,000 points, creation costs 50,000 points
- **Rush executives**: Free creation, no points consumed

### Other Consumption (Planned)

- Send special messages
- Use advanced features
- Purchase virtual items

## Points Display

### Profile

- Display current points
- Display points acquisition history (planned)
- Display points consumption records (planned)

### Chat Interface

- Display points next to username (optional)
- Display points change notifications

## Points Rules

### Points Calculation

Points are calculated and updated in real-time:

- Registration reward immediately credited
- Build incentive claimed daily
- Invitation reward credited when user registers

### Points Limits

- Points cannot be negative
- Points have no upper limit
- Points cannot be transferred (planned)
