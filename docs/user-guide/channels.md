## Channel Types

### Public Channel

Channels accessible to all users.

**Features**:
- No password required
- Visible to all users
- Can freely join and leave

### Private Channel

Channels that require a password to join.

**Features**:
- Requires password verification
- Only users who know the password can join
- Channel owner can set/modify password
- Rush executives can freely enter (no password)

## Create Channel

### Create Public Channel

1. Click the "+" button in the left channel list
2. Enter channel name
3. Select "Public Channel"
4. Click "Create"

**Points Requirement**:
- Regular users: Need 100,000 points, creation costs 50,000 points
- Rush executives: Free creation, no points consumed

### Create Private Channel

1. Click the "+" button in the left channel list
2. Enter channel name
3. Select "Private Channel"
4. Set channel password
5. Click "Create"

**Points Requirement**:
- Regular users: Need 100,000 points, creation costs 50,000 points
- Rush executives: Free creation, no points consumed

## Join Channel

### Join Public Channel

1. Click channel name in channel list
2. Automatically joins, no password required

### Join Private Channel

1. Click channel name in channel list
2. Enter channel password
3. Click "Join"

**Special Permissions**:
- Rush executives can freely enter private channels, no password required

## Channel Management

### Owner Permissions

Channel creator automatically becomes owner, with the following permissions:

- Set/modify channel password
- Modify channel information
- Upload channel logo
- Set channel rules

### Channel Rules

Channel owners can set channel rules, including:

- Wallet verification rules (NFT/Token holder verification)
- Invite code requirements
- Other custom rules

## Channel Switching

Users can switch channels at any time:

1. Click left channel list
2. Select channel to join
3. If private channel, enter password
4. Automatically switch to new channel

## Message Isolation

Messages from different channels are isolated:

- Each channel has independent message history
- Messages only display in current channel
- After switching channels, displays corresponding channel's historical messages
