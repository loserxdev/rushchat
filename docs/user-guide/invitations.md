## Invite Code

### Personalized Invite Code

Each user has a unique invite code:

- System auto-generated
- Can customize once
- Format: Alphanumeric combination

### View Invite Code

1. Click user avatar in top right corner
2. Select "Invite"
3. View personal invite code

### Customize Invite Code

1. Enter invite page
2. Click "Customize Invite Code"
3. Enter new invite code (if available)
4. Confirm modification

**Note**: Each user can only customize invite code once.

## Invitation Methods

### Share Invitation Link

1. Enter invite page
2. Copy invitation link
3. Share with friends

Invitation link format: `https://your-domain.com/?invite=YOUR_CODE`

### Share to X (Twitter)

1. Enter invite page
2. Click "Share to X" button
3. Automatically opens Twitter share interface
4. Edit and send tweet

### QR Code Share

1. Enter invite page
2. View QR code
3. Save or share QR code image
4. Friends can scan QR code to access

## Invitation Rewards

### Invitation Success Reward

When the invited user successfully registers, the inviter will receive:

- **10,000 points**
- **5 channel contribution points**

### Channel Contribution Points

Channel contribution points are used for:

- Unlock channel special features (planned)
- Display in user profile
- As activity indicator

## Invitation Statistics

Users can view invitation statistics:

- Total invitations
- Successful registrations
- Points and contribution points earned

## Register with Invite Code

### Register via Invitation Link

1. Click invitation link
2. Automatically fills invite code
3. Complete registration process
4. Inviter automatically receives rewards

### Manually Enter Invite Code

1. On registration page
2. Find "Invite Code" input box
3. Enter friend's invite code
4. Complete registration
