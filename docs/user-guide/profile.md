## Access Profile

1. Click user avatar in top right corner
2. Select "Profile"
3. Enter profile page

## Basic Information

### Username

- Set at registration
- Cannot modify
- Displayed in chat

### Email

- Optional setting
- For account recovery (planned)
- Format validation

### Wallet Address

#### EVM Address

- Supports Ethereum, BSC, Polygon and other EVM chains
- Format: `0x` prefixed 42 characters
- Automatic format validation

#### SOL Address

- Solana wallet address
- Base58 encoding format
- Automatic format validation

### Twitter

- Optional setting
- Displayed in profile
- For social links

## Avatar Settings

### Upload Avatar

1. Enter profile page
2. Click avatar area
3. Select image file (supports JPG, PNG, GIF, max 5MB)
4. System automatically compresses and uploads

### Avatar Requirements

- **Format**: JPG, PNG, GIF
- **Size**: Max 5MB
- **Dimensions**: Recommended square, system automatically crops

### Delete Avatar

1. Enter profile page
2. Click avatar area
3. Select "Delete Avatar"
4. Restore default avatar

## Password Management

### Change Password

1. Enter profile page
2. Click "Change Password"
3. Enter current password
4. Enter new password (at least 6 characters)
5. Confirm new password
6. Click "Save"

### Password Requirements

- At least 6 characters
- Recommended combination of letters, numbers, and special characters
- Regularly change password for security

## Points & Honor

### View Points

Profile displays:

- Current points
- Points acquisition history (planned)
- Points consumption records (planned)

### View Honor Level

- Current honor level (0-10)
- Level name
- Points needed for next level
