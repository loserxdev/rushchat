## System Emojis

RushChat has built-in rich system emojis, including:

- 😀 Smile
- ❤️ Heart
- 👍 Gesture
- 🎉 Celebration
- 🐶 Animal
- 🍕 Food
- ⚽ Sports
- 🌍 Location
- ⭐ Symbol

### Using System Emojis

1. Click emoji icon on the right side of input box
2. Select emoji category
3. Click emoji to send

## Custom Stickers

Users can upload custom GIF stickers.

### Upload Sticker

1. Click emoji icon on the right side of input box
2. Select "My Stickers" tab
3. Click "Upload Sticker" button
4. Select GIF file (max 5MB)
5. System automatically uploads and adds to sticker list

### Sticker Limits

- **Format**: GIF only
- **Size**: Max 5MB
- **Quantity Limits**:
  - Regular users: Up to 10
  - Admins and channel owners: Up to 100

### Sticker Management

- Each user can only see and use their own stickers
- Stickers are private and not shared with other users
- Can delete unwanted stickers

### Duplicate Detection

System uses SHA256 hash to detect duplicate uploads:

- If uploaded sticker already exists, system will prompt
- Avoids duplicate storage, saves space

## Sending Stickers

### Send in Chat

1. Click emoji icon on the right side of input box
2. Select "My Stickers" tab
3. Click sticker to send

### Sticker Display

- Stickers display as GIF animations in chat
- Supports clicking to view full size
- Maintains original animation effect
