## 踢出用户

### 操作步骤

1. 打开管理员面板
2. 找到目标用户
3. 点击"踢出"按钮
4. 确认操作

### 效果

- 用户立即断开连接
- 相同 IP 地址 60 分钟内无法进入
- 操作记录到日志

### 注意事项

- 只能踢出普通用户和下级管理员
- A级管理员可以踢出所有用户
- B级管理员不能踢出 A级管理员
- C级管理员不能踢出其他管理员

## 禁言用户

### 操作步骤

1. 打开管理员面板
2. 找到目标用户
3. 点击"禁言"按钮
4. 确认操作

### 效果

- 用户 15 分钟内无法发言
- 可以发送消息但不会显示
- 操作记录到日志

### 注意事项

- 禁言时间固定为 15 分钟
- 可以重复禁言延长禁言时间
- 禁言不影响用户观看消息

## 任命管理员

### 操作步骤

1. 打开管理员面板
2. 找到目标用户
3. 点击"任命管理员"按钮
4. 选择管理员级别
5. 确认操作

### 权限要求

- **A级管理员**：可以任命 B级和 C级
- **B级管理员**：只能任命 C级
- **C级管理员**：不能任命其他管理员

### 撤销任命

- 只有 A级管理员可以撤销其他管理员的任命
- 撤销后用户恢复为普通用户

## 置顶消息

### 操作步骤

1. 找到要置顶的消息
2. 点击消息菜单
3. 选择"置顶"
4. 确认操作

### 效果

- 消息显示在频道顶部
- 所有用户都能看到
- 可以取消置顶

### 权限

- 所有管理员都可以置顶消息
- 房主也可以置顶消息

## 查看操作日志

### A级管理员

1. 打开管理员面板
2. 点击"操作日志"
3. 查看所有管理员操作记录

### 日志内容

- 操作类型
- 操作目标
- 操作时间
- 操作者信息
- 操作详情
