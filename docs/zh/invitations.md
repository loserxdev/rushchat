# 邀请系统

RushChat 的邀请系统允许用户邀请朋友加入。

## 邀请码

### 个性化邀请码

每个用户都有唯一的邀请码：

- 系统自动生成
- 可以自定义一次
- 格式：字母数字组合

### 查看邀请码

1. 点击右上角用户头像
2. 选择"邀请"
3. 查看个人邀请码

### 自定义邀请码

1. 进入邀请页面
2. 点击"自定义邀请码"
3. 输入新的邀请码（如果可用）
4. 确认修改

**注意**：每个用户只能自定义一次邀请码。

## 邀请方式

### 分享邀请链接

1. 进入邀请页面
2. 复制邀请链接
3. 分享给朋友

邀请链接格式：`https://your-domain.com/?invite=YOUR_CODE`

### 分享到 X（Twitter）

1. 进入邀请页面
2. 点击"分享到 X"按钮
3. 自动打开 Twitter 分享界面
4. 编辑并发送推文

### 二维码分享

1. 进入邀请页面
2. 查看二维码
3. 保存或分享二维码图片
4. 朋友扫描二维码即可访问

## 邀请奖励

### 邀请成功奖励

当被邀请的用户成功注册时，邀请人将获得：

- **10,000 积分**
- **5 频道贡献值**

### 频道贡献值

频道贡献值用于：

- 解锁频道特殊功能（规划中）
- 显示在用户资料中
- 作为活跃度指标

## 邀请统计

用户可以查看邀请统计：

- 总邀请人数
- 成功注册人数
- 获得的积分和贡献值

## 使用邀请码注册

### 通过邀请链接注册

1. 点击邀请链接
2. 自动填充邀请码
3. 完成注册流程
4. 邀请人自动获得奖励

### 手动输入邀请码

1. 在注册页面
2. 找到"邀请码"输入框
3. 输入朋友的邀请码
4. 完成注册
