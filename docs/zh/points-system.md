# 积分系统

RushChat 的积分系统用于激励用户参与和创建频道。

## 积分获取

### 注册奖励

新用户注册时自动获得初始积分。

### Build 激励

- 每日可领取 1000 积分
- 每天只能领取一次
- 需要手动点击领取

### 邀请奖励

成功邀请注册用户获得：

- **10,000 积分**
- **5 频道贡献值**

### 频道贡献

通过邀请链接注册的用户，邀请人获得：

- **5 频道贡献值**

频道贡献值用于解锁频道特殊功能（规划中）。

## 积分消耗

### 创建频道

- **普通用户**：需要 10 万积分，创建消耗 5 万积分
- **Rush高管**：免费创建，不消耗积分

### 其他消耗（规划中）

- 发送特殊消息
- 使用高级功能
- 购买虚拟物品

## 积分显示

### 个人资料

- 显示当前积分
- 显示积分获取历史（规划中）
- 显示积分消耗记录（规划中）

### 聊天界面

- 用户名旁显示积分（可选）
- 显示积分变化通知

## 积分规则

### 积分计算

积分实时计算和更新：

- 注册奖励立即到账
- Build 激励每日领取
- 邀请奖励在用户注册时到账

### 积分限制

- 积分不能为负数
- 积分没有上限
- 积分不能转让（规划中）
