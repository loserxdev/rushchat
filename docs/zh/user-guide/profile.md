## 访问个人资料

1. 点击右上角用户头像
2. 选择"个人资料"
3. 进入个人资料页面

## 基本信息

### 用户名

- 注册时设置
- 不能修改
- 显示在聊天中

### 邮箱

- 可选设置
- 用于账户恢复（规划中）
- 格式验证

### 钱包地址

#### EVM 地址

- 支持以太坊、BSC、Polygon 等 EVM 链
- 格式：`0x` 开头的 42 字符
- 自动格式验证

#### SOL 地址

- Solana 钱包地址
- Base58 编码格式
- 自动格式验证

### Twitter

- 可选设置
- 显示在个人资料中
- 用于社交链接

## 头像设置

### 上传头像

1. 进入个人资料页面
2. 点击头像区域
3. 选择图片文件（支持 JPG、PNG、GIF，最大 5MB）
4. 系统会自动压缩和上传

### 头像要求

- **格式**：JPG、PNG、GIF
- **大小**：最大 5MB
- **尺寸**：建议正方形，系统会自动裁剪

### 删除头像

1. 进入个人资料页面
2. 点击头像区域
3. 选择"删除头像"
4. 恢复默认头像

## 密码管理

### 修改密码

1. 进入个人资料页面
2. 点击"修改密码"
3. 输入当前密码
4. 输入新密码（至少 6 个字符）
5. 确认新密码
6. 点击"保存"

### 密码要求

- 至少 6 个字符
- 建议使用字母、数字和特殊字符组合
- 定期更换密码以提高安全性

## 积分和荣誉

### 查看积分

个人资料显示：

- 当前积分
- 积分获取历史（规划中）
- 积分消耗记录（规划中）

### 查看荣誉等级

- 当前荣誉等级（0-10级）
- 等级名称
- 距离下一级所需积分

## 统计信息

### 账户统计

- 注册时间
- 在线时长
- 发送消息数
- 邀请人数
- 合约推荐数

### 频道统计

- 创建的频道数
- 加入的频道数
- 频道贡献值
