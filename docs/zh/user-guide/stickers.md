## 系统表情

RushChat 内置了丰富的系统表情，包括：

- 😀 笑脸类
- ❤️ 爱心类
- 👍 手势类
- 🎉 庆祝类
- 🐶 动物类
- 🍕 食物类
- ⚽ 运动类
- 🌍 地点类
- ⭐ 符号类

### 使用系统表情

1. 点击输入框右侧的表情图标
2. 选择表情分类
3. 点击表情即可发送

## 自定义表情包

用户可以上传自定义 GIF 表情包。

### 上传表情包

1. 点击输入框右侧的表情图标
2. 选择"我的表情"标签
3. 点击"上传表情包"按钮
4. 选择 GIF 文件（最大 5MB）
5. 系统会自动上传并添加到表情包列表

### 表情包限制

- **格式**：仅支持 GIF
- **大小**：最大 5MB
- **数量限制**：
  - 普通用户：最多 10 个
  - 管理员和房主：最多 100 个

### 表情包管理

- 每个用户只能看到和使用自己的表情包
- 表情包为私有，不会共享给其他用户
- 可以删除不需要的表情包

### 重复检测

系统使用 SHA256 哈希值检测重复上传：

- 如果上传的表情包已存在，系统会提示
- 避免重复存储，节省空间

## 发送表情包

### 在聊天中发送

1. 点击输入框右侧的表情图标
2. 选择"我的表情"标签
3. 点击表情包即可发送

### 表情包显示

- 表情包在聊天中以 GIF 动画形式显示
- 支持点击查看大图
- 保持原始动画效果
