# 语音聊天

RushChat 支持私有频道的 WebRTC 语音通话功能（规划中）。

## 功能概述

语音聊天允许用户在私有频道中进行实时语音通话。

## 功能特性（规划中）

### 多人语音通话

- 支持最多 20 人同时在线
- 实时音频传输
- 低延迟通信

### 语音控制

- 静音/取消静音
- 音量控制
- 麦克风开关

### 视频通话（规划中）

- 支持视频通话
- 屏幕共享
- 画中画模式

### 权限管理

- 房主控制语音权限
- 可以静音特定用户
- 可以踢出语音房间

## 使用方式（规划中）

### 加入语音房间

1. 进入私有频道
2. 点击"加入语音"按钮
3. 允许浏览器访问麦克风
4. 自动加入语音房间

### 离开语音房间

1. 点击"离开语音"按钮
2. 或关闭频道页面
3. 自动断开连接

## 技术实现

### WebRTC

使用 WebRTC 技术实现点对点通信：

- 低延迟
- 高质量音频
- 无需服务器中转（部分场景）

### 信令服务器

使用 WebSocket 作为信令服务器：

- 建立连接
- 交换 SDP
- 交换 ICE 候选
