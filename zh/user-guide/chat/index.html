    发送消息

    发送文本消息

    1. 在输入框中输入消息
    2. 按 Enter 或点击"发送"按钮
    3. 消息会立即发送到当前频道

    发送图片

    1. 点击输入框右侧的图片图标
    2. 选择图片文件（最大 5MB）
    3. 系统会自动上传并发送
    4. 支持的格式：JPG、PNG、GIF

    发送表情

    1. 点击输入框右侧的表情图标
    2. 选择表情分类
    3. 点击表情即可发送

    发送自定义表情包

    1. 点击输入框右侧的表情图标
    2. 选择"我的表情"标签
    3. 点击表情包即可发送
    4. 可以上传新的 GIF 表情包

    消息功能

    打字指示器

    当其他用户正在输入时，会在聊天界面显示"正在输入..."提示。

    在线用户列表

    右侧显示当前频道的在线用户列表，实时更新。

    消息历史

    • 自动加载历史消息
    • 支持滚动查看
    • 显示消息发送时间和发送者

    消息置顶

    管理员可以置顶重要消息，置顶的消息会显示在频道顶部。

    消息类型

    文本消息

    普通文本消息，支持 Markdown 格式（规划中）。

    图片消息

    上传的图片会以消息形式显示，支持点击查看大图。

    系统消息

    系统自动生成的消息，如用户加入/离开、频道创建等。

    合约推荐消息

    用户推荐的合约地址，支持投票和评论。
