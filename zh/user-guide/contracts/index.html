    推荐合约

    如何推荐

    1. 在聊天中输入合约地址
    2. 系统自动识别并显示为合约推荐卡片
    3. 其他用户可以看到并投票

    支持的链

    • EVM 链：以太坊、BSC、Polygon 等
    • Solana：Solana 主网

    合约地址格式

    • EVM：0x 开头的 42 字符地址
    • Solana：Base58 编码的地址（32-44 字符）

    投票系统

    投票表情

    支持 7 种表情投票：

    • 👍 支持
    • 👎 反对
    • 🌹 喜欢
    • 💩 差评
    • 🥚 一般
    • 🤮 讨厌
    • 💎 推荐

    如何投票

    1. 点击合约推荐卡片
    2. 选择投票表情
    3. 确认投票
    4. 可以随时更改投票

    投票统计

    • 实时显示各表情的投票数量
    • 显示总投票数
    • 显示平均评分

    评论功能

    添加评论

    1. 点击合约推荐卡片
    2. 滚动到评论区域
    3. 输入评论内容
    4. 点击"发送"

    查看评论

    • 所有评论按时间顺序显示
    • 显示评论者用户名
    • 显示评论时间

    内联投票

    在聊天内容中可以直接投票：

    1. 看到合约推荐消息
    2. 点击消息下方的投票按钮
    3. 选择投票表情
    4. 投票立即生效

    合约信息

    显示信息

    合约推荐卡片显示：

    • 合约地址
    • 所属链
    • 投票统计
    • 评论列表
    • 推荐者信息

    合约详情

    点击合约地址可以：

    • 查看链上信息（规划中）
    • 查看交易记录（规划中）
    • 查看持有者信息（规划中）
