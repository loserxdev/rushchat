    用户模式

    游客模式

    无需注册，一键进入聊天室。

    特点： - 自动生成唯一用户名（格式：游客XXXXXX） - 只能观看，不能发言或上传图片 - 刷新页面后用户名会改变

    使用方式： 1. 点击"以游客身份进入"按钮 2. 系统自动生成游客用户名 3. 直接进入聊天室

    注册用户

    注册要求： - 用户名：3-20个字符 - 密码：至少6个字符 - 邮箱：可选

    注册步骤： 1. 点击"注册"按钮 2. 填写用户名、密码、邮箱（可选） 3. 可选：输入邀请码（如果通过邀请链接访问） 4. 点击"注册"

    注册奖励： - 初始积分 - 个性化邀请码

    登录

    登录步骤： 1. 输入用户名和密码 2. 点击"登录" 3. 系统会自动保存登录状态

    会话保持： - 刷新页面自动恢复登录状态 - 支持多设备登录

    保留字保护

    以下用户名必须使用密码登录，不能以游客身份使用： - admin - root - administrator - system - moderator - mod - superadmin - super - owner - manager

    个人资料

    设置头像

    1. 点击右上角用户头像
    2. 选择"个人资料"
    3. 点击头像区域
    4. 选择图片文件（支持 JPG、PNG、GIF，最大 5MB）
    5. 系统会自动压缩和上传

    设置邮箱

    1. 进入个人资料页面
    2. 在邮箱字段输入邮箱地址
    3. 系统会自动验证邮箱格式
    4. 点击"保存"

    设置钱包地址

    EVM 地址（以太坊等）

    1. 进入个人资料页面
    2. 在 EVM 地址字段输入地址（格式：0x...）
    3. 系统会自动验证地址格式
    4. 点击"保存"

    SOL 地址（Solana）

    1. 进入个人资料页面
    2. 在 SOL 地址字段输入地址（Base58 格式）
    3. 系统会自动验证地址格式
    4. 点击"保存"

    修改密码

    1. 进入个人资料页面
    2. 点击"修改密码"
    3. 输入当前密码和新密码
    4. 确认新密码
    5. 点击"保存"

    用户权限

    普通用户

    • 发送消息
    • 上传图片
    • 创建频道（需要 10 万积分）
    • 上传表情包（最多 10 个）

    管理员

    • 所有普通用户权限
    • 踢出用户
    • 禁言用户
    • 置顶消息
    • 上传表情包（最多 100 个）

    房主

    • 所有普通用户权限
    • 设置频道密码
    • 修改频道信息
    • 上传表情包（最多 100 个）

    积分系统

    积分获取

    • 注册奖励：注册用户默认积分
    • Build 激励：每日可领取 1000 积分
    • 邀请奖励：成功邀请注册用户获得 10,000 积分
    • 频道贡献：通过邀请链接注册的用户，邀请人获得 5 频道贡献值

    积分消耗

    • 创建频道：消耗 5 万积分（Rush高管免费）

    荣誉等级

    荣誉等级共分为 11 个等级（0-10级），根据总积分自动计算。

    等级 积分范围 等级名称
    0级 0-99分 新手
    1级 100-199分 入门
    2级 200-299分 初级
    3级 300-499分 中级
    4级 500-799分 高级
    5级 800-1299分 资深
    6级 1300-1999分 专家
    7级 2000-2999分 大师
    8级 3000-4999分 传奇
    9级 5000-7999分 神话
    10级 8000+分 传说

    评分机制

    1. 在线时长：每在线 60 分钟 = 1 分
    2. 邀请人数：每成功邀请 1 人 = 10 分
    3. 消息数量：每发送 100 条消息 = 1 分
    4. 消息点赞：每个点赞 = 2 分
    5. 合约推荐：每推荐 1 个合约 = 5 分
    6. 推荐评分：平均投票分数 × 10
